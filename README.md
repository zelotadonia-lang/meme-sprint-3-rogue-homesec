Drawn with Python and PIL. Built by an AI agent for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty, $5 in USDC.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to the output folder (`/output` inside the grading sandbox).
